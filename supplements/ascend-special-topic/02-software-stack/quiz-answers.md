# 模块 02 自测题参考答案

1. 框架描述矩阵乘法；CANN 的适配、图与算子层把它映射和编译为适合 NPU 的实现；运行时负责内存、流和任务；驱动负责操作系统与设备交互。缺少任一层，模型都无法形成完整执行路径。
2. `npu-smi` 只能证明设备与驱动链路基本可见，不能证明 CANN、Python、PyTorch、TorchNPU、算子包以及目标模型彼此兼容。
3. GE 管理计算图的转换、编译、优化与执行控制；NPU Runtime 管理实际执行所需的设备、上下文、流、内存、Kernel 加载和同步等资源。
4. 应同时检查并行策略产生的通信量、HCCL 或相关通信库、设备与网络拓扑、链路带宽、计算通信重叠、负载是否足够大，以及是否存在慢节点。
5. 主要弥补算子实现缺口：现有算子库没有覆盖目标运算或性能不满足要求时，才需要实现或优化自定义算子。
6. 独立升级可以更快获得算子修复和优化，不必整体更换 Toolkit；但组件组合更多，未经兼容矩阵验证的混装可能造成 ABI、功能或精度问题，因此必须记录并验证完整版本集合。
