# D29 自测题参考答案

1. A 的下一 Token 要等待 B 的长 Prefill 完成，流式输出可能出现明显停顿，后续 Token 的等待时间和 TPOT 尾部升高。
2. B 的剩余 Prompt 尚未处理，完整 KV Cache 还没形成；只有全部 Prefill 块完成后才能基于整个输入生成。
3. 会减少每轮有效工作规模、增加调度和 Kernel 开销，并让长 Prompt 需要更多轮才能完成。
4. 跨轮保留状态还需要 KV Cache；缓存预算不足时，仅有本轮计算预算也不能接纳。
5. 固定批次把一组请求绑定到完成；连续批处理在生成迭代之间重新选择活动请求和 Token。
6. 还要关注新请求 TTFT、Prefill 总完成时间、GPU 工作规模与总体吞吐，不能只让块越小。
