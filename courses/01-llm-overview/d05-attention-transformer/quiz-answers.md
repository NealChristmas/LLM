# D05 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。答案重点是理解“匹配—加权汇总—多视角—逐层加工”这条机制链。

1. **Transformer 是处理序列的神经网络架构，不是单个公式。**典型层中，Attention 跨 Token 汇总信息，FFN 逐 Token 加工信息，残差连接保留原表示并提供直接通路，LayerNorm 调整数值尺度以支持稳定堆叠。
2. Query 像检索条件，说明当前位置想找什么；Key 像记录的可检索特征，用于计算匹配程度；Value 像匹配成功后真正读取的记录内容。用于匹配的特征与需要取走的信息职责不同，因此分别生成 Key 和 Value。
3. A 的权重是 **e⁰/(e⁰+e¹)≈0.269**，B 的权重是 **e¹/(e⁰+e¹)≈0.731**。B 的分数更高，因此它的 Value 权重更大，但对最终向量的实际影响还与 Value 本身有关。
4. 模型顶部的下一 Token 预测与正确目标计算交叉熵损失。损失的梯度从输出反向穿过后续层和 Attention，沿 Q=XWQ、K=XWK、V=XWV 分别得到 WQ、WK、WV 的梯度；优化器据此同时更新它们。因此，中间的 Q/K/V 不需要人工标签。
5. FFN 对序列中的每个 Token 行分别应用同一组两层参数和非线性变换，不在这一步读取其他位置。Attention 负责跨 Token 移动和汇总信息，FFN 只加工当前位置已经汇总到的表示。
6. 当 F(x) 接近 0 时，y=x+F(x)≈x，所以原信息仍能沿 x 的支路保留。**∂y/∂x=I+∂F/∂x 中的 I**来自直接加法支路，提供不必完全穿过 F 的梯度通路。
7. μ=(1+2+3)/3=2；σ²=[(1−2)²+(2−2)²+(3−2)²]/3=2/3。LayerNorm 在这里归一化的是**单个 Token 向量内部的三个特征维度**，不是把不同 Token 混在一起计算。
8. D04 先把 Token 映射为 Embedding 并加入位置信息。每层 Transformer 用多头自注意力跨位置汇总上下文，再用 FFN 逐位置加工，并由残差连接和层归一化支撑堆叠；多层输出成为上下文化隐藏状态。D06 还要说明怎样限制未来信息、把隐藏状态转成 Logit 和概率、选择 Token，并循环生成。
