# 调压站智能体华为计算卡核算表

生成日期：2026-10-09。打开 [Excel 自动核算表](调压站智能体-华为计算卡自动核算.xlsx)，填写黄色单元格，顶部自动显示主模型容量下限、采购规划卡数和服务器数量。客户填写峰值请求、模型调用次数、活动并发、上下文与延迟目标；研发填写实际模型、精度与部署参数；供应商填写同配置并发压测证据。默认值是可修改的规划假设，空白项没有假定客户数据。

详细规则见 [核算规则与完整算例](calculation-rules.md)，包括所有核心公式、Excel 单元格对应、多卡副本装箱、备用与容灾的区别，以及缺项处理。版本 1.1 已修正按完整副本计算服务器台数，主模型与辅助卡按相同插槽容量、分开部署规划；同一副本须位于一台服务器。

**容量下限与采购数量含义不同。** 容量按权重、KV Cache、运行时内存与可用内存预算计算。采购数量取容量需求与达标吞吐/并发需求的较大副本数，再加入在线备用副本及辅助模型用卡。没有有效压测或兼容性确认时，采购数量保持待核算。表格内“硬件与依据”列出官方参考、单位、核对日期和计算边界。

本表适用于一个主模型的本地推理。MoE 权重使用总参数量；标准 MHA/GQA 使用结构公式，MLA 或混合注意力使用自定义 KV 内存。多卡分组必须确认单芯片峰值内存、切分与通信可行。按相同副本线性扩容是规划近似，最终须在完整系统复测。备用副本并不自动保证整机容灾；整机或模组采购按供应商 BOM 确认口径。

已使用表格计算引擎验证 16 项判断，记录在 [验证记录](verification.json)，并扫描公式错误、检查两张工作表的渲染。合成样例已恢复为空白，不是客户压测。没有在本机原生 Excel / WPS 中验证交互重算，也没有开展华为硬件实测。若打开后未自动重算，请将表格软件计算模式设为自动，并使用实际客户参数复核。
