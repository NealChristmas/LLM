# D25 自测题参考答案

1. 约 9 倍，因为分数元素数量与 T² 成正比，3000²÷1000²=9。
2. 后续分块可能出现更大分数，需要重新缩放此前累计量；这些统计量允许正确合并各块而不保存所有分数。
3. 它没有消除标准全注意力的大部分 Query-Key 比较，核心计算规模仍随序列长度平方增长。
4. 不正确。它主要通过分块和重排数据访问实现精确注意力，不是删除低分项的稀疏近似。
5. Prefill 同时有许多 Query，Decode 每步通常只有新 Query 并读取历史 KV；形状与访存模式不同。
6. 二者都尽量让中间数据留在片上并减少显存往返，但 FlashAttention还依赖可分块合并的注意力算法。
