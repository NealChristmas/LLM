# D13 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。答案重点是理解状态、控制路径和停止条件怎样共同保证多步骤任务可控。

1. 查票结果可能超预算、信息可能缺失，创建操作也可能需要用户确认。固定直线流程看不到这些中间条件，容易在不该继续时继续执行。
2. 步骤稳定、分支可列举、风险较高或需要严格审计时优先工作流；环境变化大、所需步骤依赖中间结果且难以穷举时，可在受控范围内使用 Agent 动态决策。
3. 程序固定总体阶段和安全边界，模型只在开放节点选择动作。例如模型可以比较交通方案，但进入“创建申请”节点前必须经过程序固定的摘要展示和用户确认。
4. 对话可能因窗口限制被截断，模型也可能复述错误或混淆计划与结果。申请状态应由外部存储和审批系统的真实返回值记录，再按需放入上下文。
5. 缺少最大步骤、重试次数、时间或成本预算等停止条件，也可能缺少对重复失败的识别和人工接管规则。
6. 超时不等于失败，第一次调用可能已经创建成功。直接重试可能重复产生副作用，应使用幂等请求标识或先查询原操作状态。
7. 至少应保存任务目标、每步输入与模型决策、调用的工具和参数、校验结果、工具响应、状态变化、用户确认以及最终停止原因。

第 1～3 题不清楚时回看第 1～4 节；第 4 题回看第 5 节；第 5、6 题回看第 6 节；第 7 题回看第 7 节。
