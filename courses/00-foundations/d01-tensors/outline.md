## 1. 本课主线与范围

先读[整体知识地图](../../../knowledge-map.md)，分清模型产生与请求处理两条流程，认识计算、训练、应用、服务和评测的位置。随后聚焦 P1 数值计算，从“用两个输入特征计算一个预测值”出发，理解张量、参数与基础前向计算。

本章拼图定位：P1 同时是训练与推理的计算基础。今天补上“数值输入 → 参数计算 → 数值输出”；文本如何成为这些数字由 P4 展开，参数如何改变由 D02 的 P2 接续。地图上的其他术语先知道用途，不要求记住机制。

整体导读采用“根据项目文档解释部署步骤，再查询服务状态”的案例。进入 P1 后，用两个无量纲的合成特征预测一个分数作为可手算的局部实验；先处理一个样本，再同时处理三个样本。明确这只演示数值计算机制，不是能理解文本的语言模型。小型隐藏层作为选学。

本课必学：整体两条流程；标量、向量、矩阵、张量（Tensor）、形状（shape）、样本与特征、逐元素运算、矩阵乘法、权重、偏置和基础前向传播。

本课选学：隐藏层、ReLU 激活函数与 2 → 3 → 1 小网络。其作用会在后续模型结构课程重新解释，不作为 D01 前置门槛或必交作业。

本课只认识：dtype 表示元素的数据类型，device 表示计算设备；用最小例子联系大模型中的批次、Token 和向量表示。

后续再学：参数如何学出来、损失函数、梯度、反向传播、Softmax、Attention、GPU 性能。张量的 strides、复杂广播规则及高阶线性代数不计入本课。

## 3. 概念热身与实验条件

已确认有 3 年 C++ 和 JavaScript 开发经验，省略变量、列表、函数及脚本执行等编程教学。本课数学从必要的形状与加权求和讲起；代码用于验证概念，Python/PyTorch 特殊语义仅按需简述。

概念热身拟定：

1. 三个样本、每个两个特征应怎样组织，两个轴分别代表什么？
2. 在 y = x₁w₁ + x₂w₂ + b 中，哪些是本次输入，哪些是模型参数？
3. 计算一次输出和根据误差改变参数，分别属于整体流程的哪部分？

热身用于暴露待讲的数学与模型概念，不要求课前全答对。后续解释对应误解，不安排编程补课；必要运行命令仍简要给出。

环境计划：Windows PowerShell、Python、PyTorch CPU；不需要 GPU、模型权重或付费服务。正式资料生成时确认适用版本、安装步骤和运行结果，当前大纲不声称代码已验证。

## 5. 正文拟定章节

### 第 0 节：大模型全貌与第一块拼图

- 模型与聊天产品分别包含什么：数据、参数、应用程序、外部知识、工具、服务与评测。
- 模型产生：数据准备、预训练、按需后训练、评测和交付版本。
- 请求处理：接收问题、按需补充资料、编码输入、模型计算、按需工具执行、返回回答。
- GPU 与推理服务支撑计算，评测贯穿全过程；检索和工具不是每次请求的必经步骤。
- 用项目文档与服务状态的例子走一遍流程，指出 P1～P9 各自回答的问题。
- 把镜头落到 P1：今天只补全“数值输入如何变为输出”。

### 第 1 节：模型接收的数据长什么样

- 从一个数、一条样本、多个样本，引出标量、向量和矩阵。
- 在本课计算语境中，把 Tensor 理解为组织数值的多维数组；不展开数学上的一般张量定义。
- 用 shape = [3, 2] 表示三个样本、每个两个特征，区分“轴的数量”“每个轴的长度”“元素总数”。
- 明确 shape 只描述大小，轴的含义由数据约定决定，不能看到两维就一律解释为样本和特征。
- 即时检查：增加一个样本或一个特征，形状分别怎么变？

### 第 2 节：模型如何把输入组合起来并完成前向计算

- 从 y = x₁w₁ + x₂w₂ + b 解释输入、权重、偏置和输出。
- 用小整数手算一次，解释修改输入、权重和偏置分别意味着什么。
- 把多个样本整理成 X，把多个输出的权重整理成 W，得到 XW + b。
- 讲清 [B, F] × [F, O] → [B, O]：B 为样本数，F 为输入特征数，O 为输出特征数。
- 对比相同形状矩阵的逐元素乘法与矩阵乘法，不混淆两种操作。
- 仅演示一个长度为 O 的偏置向量加到每个样本这一种广播用法。
- 即时检查：为什么 [3, 2] 不能直接与 [3, 1] 做矩阵乘法？
- 把一次 XW + b 称为本课简单模型的前向计算；参数由人指定，运行不会自动学习。
- 回到地图：训练也使用前向计算，但还需要误差与更新步骤；推理使用已有参数计算输出。

### 选学：怎样连接一个隐藏层

- 把“输入 → 加权求和与偏置 → 激活 → 输出”连接起来，定义前向传播（forward pass）。
- 引入 ReLU：负值变为零，非负值保持不变；展示它如何改变中间结果。
- 用直观解释说明非线性的用途：只有线性或仿射运算时，多层仍可合并为一个仿射变换；推导列为选学。
- 标出一个 2 → 3 → 1 小网络的形状，分别解释批次大小与层宽度。
- 参数在本课中人为指定；执行一次前向计算不会因此自动更新参数。
- 最后用少量文字连接大模型：数值表示和张量计算将反复出现，Token 的具体编码留到后续课时。

## 6. 引导实验设计

### 实验 A：认识张量与形状（20 分钟）

创建标量、长度为 2 的向量及形状为 [3, 2] 的矩阵；先预测 shape，再观察实际输出。查看 dtype 和 CPU device，但不扩展到设备迁移。增加一个样本，解释哪个轴改变。

### 实验 B：让手算和程序对应起来（30 分钟）

使用 X = [[1, 2], [3, 4], [5, 6]]、W = [[2], [3]]、b = [1]，计算 XW + b。学习者先手算首个样本，运行后对照三个样本的输出。再修改一个权重并预测变化。

在独立的小例子中对比逐元素乘法和矩阵乘法；刻意制造一次形状不匹配，按错误信息定位内维度。这里的 W 按数学写法采用 [输入特征, 输出特征] 布局；D01 直接做张量运算，不混入高层线性层内部权重布局。

### 选学实验 C：连接一个小型网络（另计约 25 分钟）

固定 X 的形状为 [3, 2]，W₁ 为 [2, 3]，b₁ 为 [3]，W₂ 为 [3, 1]，b₂ 为 [1]。计算隐藏层 ReLU(XW₁ + b₁) 和最终输出，打印每一步形状。正式讲义选用便于手算、能产生正负中间值的固定参数。

让学习者预测一个中间结果，修改一个参数，观察输出；解释“执行预测”和“学习参数”之间的差别。实验结束保留一个问题给 D02：参数应该怎样根据预测误差调整？

## 8. 闭卷验收、补练与复习

闭卷复述：模型怎样产生，一次回答怎样产生？今天补全了哪里？数据怎样组织成张量？矩阵乘法把哪个维度组合起来？权重与输入有什么区别？为什么有输出不代表模型已学习？

通过依据：G1～G4 均有能独立完成的证据，能够解释并修正形状错误。允许查 API 拼写，不以记忆函数名评分。若形状或矩阵乘法仍不清楚，安排针对性小练习再进入 D02；不凭阅读完毕记录为掌握。

复习建议：D02 开头重画计算链，D04 再判断一组新形状，约一周后闭卷解释前向与训练的区别。时间可随实际进度调整。
