# D20 自测题参考答案

1. 它们的数据搬运量、复用程度、并行度和 Kernel 效率可能不同；FLOPs 只描述运算数量。
2. B×I=30 byte/s×2 FLOP/byte=60 FLOP/s，表示显存每秒提供的数据最多支撑 60 FLOP。计算上限为 120 FLOP/s，取较小值得 60 FLOP/s，因此更可能带宽受限。
3. B×I=30 byte/s×6 FLOP/byte=180 FLOP/s，数据供给已经能支撑 180 FLOP/s，但计算单元最多完成 120 FLOP/s，因此取较小值得 120 FLOP/s，限制转为计算上限。
4. 主要耗时在等待数据时，减少一部分本来就不是主导项的计算不会消除主要等待。
5. Prefill 同时处理许多 Token，同一权重块可以参与更多乘加；小批次 Decode 每步新增数据少，复用机会较少。
6. 不应。还要检查批次是否太小、任务切分、Kernel 启动、同步、CPU 提交以及请求调度造成的空隙。
