# D32 自测题参考答案

1. 榜单的模型、硬件、精度、长度和并发可能与目标不同，且所需模型或功能组合可能不受支持。
2. 不满足硬约束的候选即使很快也无法正确交付；先筛掉不可用组合可以避免无意义测试。
3. 前缀缓存或其他能复用完全相同 Token 前缀 KV Cache 的机制，并测量真实命中率、TTFT、缓存占用和吞吐。
4. 它面向 NVIDIA GPU 提供量化、批处理、缓存和多卡等深度优化；同时要考虑支持矩阵、构建调优、升级和团队维护成本。
5. 不能。精度差异同时改变内存、带宽、Kernel 和质量；需要使用等价配置或明确拆分变量。
6. 除质量与完成率、峰值显存和成本，还应记录模型与功能兼容、部署升级难度、可观测性、故障诊断和团队熟悉度；测试配置中还应记录 tokenizer、模板、预热与缓存状态，保证结果可复现。
7. 明确用户症状与负载 → 拆分 Prefill/Decode/排队 → 判断计算、带宽、容量或调度瓶颈 → 选择针对性机制 → 检查引擎和硬件支持 → 在等价条件下验证质量、延迟、吞吐与成本。
