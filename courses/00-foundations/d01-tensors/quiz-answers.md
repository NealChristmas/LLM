# D01 自测参考答案

先完成[章末自测](README.md)，再核对。答案用于修正理解，不要求逐字背诵。

| 题号 | 答案与理由 |
| --- | --- |
| 1 | 输入从 1 变成 4；参数 w = 3、b = 2 不变；输出从 5 变成 14。**结果变化可以由输入变化造成，不代表参数更新。** |
| 2 | 四条样本，每条两个特征，共八个数。shape 只描述大小，“行是样本”来自题目的约定，不能仅凭 shape 推断业务含义。 |
| 3 | 两个输入数只能与两个权重配对；第三个权重缺少对应输入。错误来自计算关系不匹配。 |
| 4 | 输出从 [3,1] 变为 [5,1]。仍用原来两个权重；如果包含原有共享偏置，偏置也不增加，因此参数数量不变。 |
| 5 | 原输出为 1×2 + 2×3 + 1 = 9；改后为 1×4 + 2×3 + 1 = 11，增加 2。变化量是第一个输入 1 乘权重变化 2。 |
| 6 | 本例没有计算误差、更新参数的步骤。相同输入和固定计算得到相同结果，重复次数不会自动变成训练。 |
| 7 | 模型内部执行数值计算，需要可参与运算的表示。本章讲“用参数处理输入数字”；文字如何编码为表示、数值结果怎样用于生成文字，将在后续展开。 |

优先检查第 1、4、6 题，它们共同检验是否分清输入、参数和计算。第 2、3 题若有困难，回到第 4 节配图；第 7 题用来接回整体知识地图。纠正误解后即可继续 D02，不必做旧实验或长练习。
