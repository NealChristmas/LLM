# 第 4 节之后：如果每条输入要得到多个结果

做 E4 前阅读；先确认已能解释 [3,2] 与 [2,1] 相乘为什么得到 [3,1]。

原来每条输入使用权重 2、3 得到一个结果。如果还想得到另一个结果，可以另外准备一套权重，例如 1、0。对于输入 [1,2]，两套规则分别计算：

```text
第一个结果：1×2 + 2×3 = 8
第二个结果：1×1 + 2×0 = 1
```

将每套规则排成一列，权重矩阵变为：

```text
W = [[2, 1],
     [3, 0]]
```

第一列仍是原来的权重，第二列产生新结果。原来三条输入组成的 X 与它相乘，得到 [[8,1],[18,3],[28,5]]，shape 为 [3,2]。每个结果行对应一条输入，每个结果列对应一套权重。

所以需要几个输出，就准备几列权重。若每条输入有 F 个数，每条产生 O 个结果，W 为 [F,O]。同时处理 B 条输入时，X 为 [B,F]，结果为 [B,O]。这些字母只是把刚才的具体数量换成了名称。

再加上偏置。假设第一个结果加 1，第二个结果加 10，偏置向量为 [1,10]：

```text
[ 8, 1] + [1,10] = [ 9,11]
[18, 3] + [1,10] = [19,13]
[28, 5] + [1,10] = [29,15]
```

每条输入都使用相同的两个偏置。框架允许直接把形状为 [2] 的偏置加到 [3,2] 的结果上，表现为逐行添加，这个用法叫广播。它没有为每条输入增加独立的模型参数。

本例权重数为 2×2 = 4，偏置数为 2，总参数数为 6。改变批次的样本数不改变这些参数。现在可以尝试[练习 E4](exercises.md)。

数值为教学手算示例；不作为新增代码实测记录。广播依据见[PyTorch 官方说明](https://docs.pytorch.org/docs/2.14/notes/broadcasting.html)。
