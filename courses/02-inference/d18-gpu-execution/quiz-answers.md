# D18 自测题参考答案

1. CPU 侧把文字 Tokenize 并组织请求，Token ID 进入 GPU 后通过 Embedding 查表得到输入向量；框架按模型结构发起算子，后端选择 GPU Kernel；Kernel 读取输入和权重、并行计算并写回新隐藏向量。
2. GPU 是否繁忙还取决于每次处理的数据规模、可并行工作数量、数据搬运和调度开销。参数多只说明潜在工作量和存储量大。
3. 它们共享模型权重和同类计算规则；各自的输入、中间激活、注意力边界、KV Cache 与输出位置仍然独立。
4. 后一个算子需要前一个算子的输出；在输出尚未产生时启动后一个算子，没有完整输入可用。
5. Prefill 一次处理许多 Token，计算规模较大；Decode 每步只增加少量 Token，并反复读取不断增长的 KV Cache，因此并行规模和数据访问比例不同。
6. 不一定。如果瓶颈是显存读写而不是计算能力，增加计算单元仍要等待数据，收益会很小。
