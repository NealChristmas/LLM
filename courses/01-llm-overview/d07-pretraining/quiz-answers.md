# D07 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。答案重点是把“一道预测题”逐步扩大成“大量文本怎样塑造基础模型”。

1. “机器”预测“学习”；“机器 学习”预测“改变”；“机器 学习 改变”预测“世界”。答案是原序列中紧邻右侧的真实 Token，由文本自身提供，不需要人工逐题标注。
2. 模型先做前向计算，得到包括“咖啡”在内的全词表概率；用正确答案“咖啡”的概率计算交叉熵并汇总损失；反向传播计算各相关参数对损失的梯度；优化器更新参数一次，使模型倾向于在类似上下文中提高正确 Token 的概率。
3. 多个位置可以在矩阵计算中同时处理，但因果遮罩分别阻止每个位置读取右侧 Token。计算上的并行不会改变每个位置的信息边界。
4. 一句话只带来一次局部更新；许多不同上下文从多个方向反复提供相互关联的训练信号，能让参数捕捉“咖啡”与其他概念之间较稳定、可迁移到新句子的关系，而不是只适应一段固定文字。
5. 翻译、问答等模式本身也存在于文本中。要在这些上下文里正确预测后续 Token，模型需要识别任务形式、结合上下文并延续相应输出；这些能力是为降低同一个下一 Token 损失而形成的，不是换了另一个预训练目标。
6. 语言模型通过参数表示从文本中压缩出的预测规律，没有执行带来源和更新时间的精确记录查询。正确回答可能来自稳定的事实关联，但同一机制在数据冲突、覆盖不足或知识过时时也可能生成错误内容。
7. 错误。更多参数只提供更大的表示容量；如果数据数量、质量或训练计算没有匹配，新增参数未必得到充分而有效的训练，具体能力不保证改善。
8. 大量文本自动产生下一 Token 答案，预测误差形成损失和梯度，许多训练步反复调整参数，使共同规律逐渐沉淀成基础能力。它仍可能不按指令回答，因为预训练目标要求延续文本，没有专门定义理想助手行为。

第 1～3 题不清楚时，回看正文第 1、2 节；第 4、5 题不清楚时，回看第 3、4 节；第 6～8 题不清楚时，回看第 5～7 节。
