# D33 自测题参考答案

1. 不能。系统内存不是 GPU 显存，没有 NVIDIA GPU 就无法据此完成 CUDA GPU 实验；最多可以选择 CPU 等另一条执行路线。
2. `nvidia-smi` 是 NVIDIA 驱动提供的系统工具，不属于普通 Python 包。还要结合设备列表判断是没有 NVIDIA GPU、未安装驱动，还是命令路径异常。
3. 不能。`docker-desktop` 是 Docker Desktop 的内部发行版，不等于已经安装并配置供课程使用的 Ubuntu。
4. 它是集成显卡，不属于本课程准备验证的 NVIDIA CUDA 主线，无法提供所需的独立显存与相同 Kernel、监控和多卡实验条件。
5. 不应未经验证直接沿用。可以改用合适的量化权重或更小模型，然后重新建立统一基线；也可以换用显存更大的 GPU。
6. GPU 型号、显存、计算能力、驱动环境和持久化方式必须先满足实验要求；价格最低但无法运行目标负载的实例没有意义。
7. 至少固定模型版本与精度、推理引擎版本、硬件类型、输入输出负载和测量方法，后续对比才有解释力。
