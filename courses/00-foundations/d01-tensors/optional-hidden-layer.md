# 选学：加上隐藏层与 ReLU

额外约 25 分钟，不计入 D01 必学。先完成[主讲义](README.md)。这里仍使用固定参数，不训练模型。

隐藏层是输入与最终输出之间的中间表示。让两维输入先变成三维，再变成一维：

| 步骤 | 运算 | 形状 |
| --- | --- | --- |
| 输入 | X | [3, 2] |
| 第一层 | Z = XW₁ + b₁ | [3, 3] |
| 激活 | H = ReLU(Z) | [3, 3] |
| 输出层 | Y = HW₂ + b₂ | [3, 1] |

W₁ 是 [2, 3]，b₁ 是 [3]；W₂ 是 [3, 1]，b₂ 是 [1]。第一个 3 表示样本数，隐藏层的第二个 3 表示中间特征数，两者恰好相同，意义不同。

ReLU 对每个元素取 max(0, z)：负数变零，非负数保持原值。它改变数值而不改变 shape。非线性的意义在于：如果各层只有矩阵乘法和偏置，组合后仍是一个仿射变换；加入非线性后可以表示更丰富的映射。这并不意味着用了 ReLU 就能完成任意任务，结构、参数与数据仍然重要。

本例参数为：

```text
W₁ = [[1, -1,  2],    b₁ = [0, -2, 0]
      [1,  1, -1]]
W₂ = [[1], [2], [-1]], b₂ = [1]
```

先手算第一条输入 [1, 2]：Z = [3, -1, 0]，H = [3, 0, 0]，Y = 4。对其余样本预测后，在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe courses/00-foundations/d01-tensors/code/experiments.py c
```

应观察到 Z 为 [[3,-1,0],[7,-1,2],[11,-1,4]]，H 将中间列的 -1 变为 0，最终输出为 [[4],[6],[8]]。这些都是预先指定参数的前向结果，没有学习过程。
