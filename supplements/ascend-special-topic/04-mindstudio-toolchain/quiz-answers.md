# 模块 04 自测题参考答案

1. MindSpore 是模型框架，CANN 是昇腾计算基础软件，MindIE 是推理与服务化体系；MindStudio 是迁移、精度、性能、内存、算子和监控工具集合。模型可沿框架或引擎、CANN、NPU 的路径运行，只有需要开发或诊断时才调用相应 MindStudio 工具。
2. 最终输出只显示偏差已经累积到结果，不能指出首个异常层。msProbe 通过在标杆与目标环境采集相同层级的数据，先粗后细比较，缩小到首次明显偏离的模块、API 或算子。
3. 算子可能只占少量请求，或与其他计算重叠；端到端瓶颈也可能来自排队、Host 空洞、通信或同步。要结合阶段占比、关键路径和并发时间关系判断。
4. 不能。还需固定评测集验证任务质量，检查关键样例和精度偏差，并在相同硬件、引擎和负载下测量内存、时延、吞吐和稳定性。
5. 采集各 Rank 的计算与通信时间线、集合通信耗时、Host 下发、输入数据等待、设备利用率和拓扑信息，再检查是否有慢 Rank、数据不均衡或通信未被计算掩盖。
6. 自动迁移只证明工具完成了可识别的语法或 API 变换。标杆输出用于验证语义和精度，变更清单用于审查自动与人工修改、追踪回归并支持复现。
7. 固定请求和负载复现 TTFT 升高；提出一个假设，如队列等待增加；用服务级 Profiler 采集请求到调度和 Prefill 的时间线；保存原始数据；只调整准入或批处理参数；用同一负载复测 TTFT、吞吐和完成率。若假设不成立，再转向 Prefill 算子或设备数据。
