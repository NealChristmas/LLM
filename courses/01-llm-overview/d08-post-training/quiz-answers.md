# D08 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。答案重点是先分清模型经历的三个训练阶段，再分清“训练信号”和“参数更新范围”。

1. 预训练要求模型预测普通文本的下一个 Token，没有专门要求它把用户文字识别成必须执行的指令。因此能够续写却不稳定执行格式要求是可能的，后续 SFT 才用指令示范专门调整这一行为。
2. SFT 样本包含总结指令、待总结原文和一个忠于原文的三点式理想回答。偏好数据包含同一个指令和原文、至少两个候选回答，以及哪个回答更好的比较结果。
3. 同一任务通常有很多可行回答，单个示范主要展示“怎么做”，难以表达所有质量取舍。偏好数据可以指出两个都像答案的结果中，哪个更忠实、简洁或安全。
4. 对同一提示生成多个回答，由人类比较优劣；用比较数据训练奖励模型；奖励模型为语言模型生成的新回答打分；强化学习根据奖励调整语言模型，使高分回答更容易出现。奖励模型把有限的人类比较推广成可反复提供的评分信号。
5. 错误。DPO 属于偏好优化，但它直接用偏好对形成训练目标，不需要独立奖励模型和强化学习阶段。经典 RLHF 才通过奖励模型与强化学习利用偏好。
6. 按正文的矩阵方向，一个矩阵为 8×1024，另一个为 1024×8，共有 8×1024+1024×8=16,384 个参数。完整矩阵有 1024×1024=1,048,576 个参数，所以两个小矩阵的参数量是其 1/64。
7. SFT 回答“用什么数据和目标产生梯度”，LoRA 回答“梯度允许更新哪些参数”。可以用 LoRA 只训练低秩增量，同时用 SFT 的指令—回答数据作为训练信号。
8. 微调把信息写入参数，资料变化后需要再次训练，而且难以像文档检索一样明确返回来源；它也不能保证事实准确。更适合的方向是后续 D10～D11 的检索与 RAG，把最新资料在请求时放入上下文并保留来源。
