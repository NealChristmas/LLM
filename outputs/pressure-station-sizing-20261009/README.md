# 调压站智能体华为计算卡估算表

版本：2.0，更新：2026-10-09。打开 [Excel 自动估算表](调压站智能体-华为计算卡自动核算.xlsx)，使用第一张“粗略估算”。必需输入均有默认值，优先调整两个黄色字段：**高峰同时处理的任务数、高峰每分钟业务请求数**。其余蓝色字段可以先保留，无须先提供模型结构参数或压测报告。

默认场景为 14B 模型、64GB 级单芯片卡、10 个同时任务、每分钟 2 个业务请求、每业务 3 次模型调用、20% 增长余量及 1 组备用。每副本按 4 路并发、每分钟 10 次模型调用的预算假设计算，初步结果为 **4 张卡**。所有这些值都可修改；默认能力没有硬件实测，结果只代表该预算场景。

- [粗略估算规则与默认算例](calculation-rules.md)：解释默认值、自动多卡分组、副本数、预算卡数及服务器装箱。
- [详细核算规则（可选）](detailed-calculation-rules.md)：保留模型结构参数和达标压测的精化方法，对应第二张“填写与核算”。
- [公式验证记录](verification.json)：粗估分支 10 项、详细分支 16 项，共 26 项判断检查；已检查导出与渲染。

“硬件与依据”保存官方来源与可修改的共同内存假设。粗估表假设模型能按分组切分，备用副本不自动保证整机容灾；特殊模型、模组服务器和跨机部署按实际方案确认。未在原生 Excel/WPS 或华为硬件验证性能；若表格未自动重算，可在表格软件中启用自动计算。
