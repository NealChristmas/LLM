# V2 客户报告与图

输出report.client.md、report.evidence.md、report.json及sizing-flow.svg（必要时PNG）。报告章节固定为：

1. 需求与部署条件：明确布局是否固定；列物理卡、推理实例和关键依据/预算假设及来源状态。
2. 计算规则：中文变量关系，不带本轮数字，分别保留显存、Prefill、Decode及完整组与备用。
3. 理论测算过程：规划负载→权重与缓存显存→平均TTFT→TPOT→约束对照/敏感性→布局选择及工作/备用卡。没有“独立核对基线”章节。
4. 结论与适用范围：候选来自哪个理论方案、更小布局是否评估、未建模项及部署验证计划。不把无实测结果写成达标承诺。

开头写“当前参考布局的预算候选”，若只评估一种布局，紧接“更小布局尚未评估”。不只给一个醒目卡数。正文表格最多三列，目标对照同时显示预算值、约束和证据状态；敏感性表展示TTFT/TPOT变化，不能只重复相同卡数。小数按粗估精度展示，计算使用未舍入值。

每条计算先给中文变量公式，再带数字，连续同一条等式。例如“单请求Prefill工作量≈输入Token数×2×每Token的Prefill激活参数量≈8,000×（2×80亿）＝128 TOP”。由阅读器自然换行，不主动拆成变量/数字两段。TOP为工作量，TOPS为每秒处理能力；TTFT/TPOT单位就近标注。第二章与第三章的算法须一致。

附录保存模型与硬件来源、修订/摘要、采用字段、假设、公式算法及脚本身份、缓存分项/复制、运行预留、通信和卸载、未覆盖项及复算方式。不要在客户正文描述内部历史ID和导入实现。实际未验证的分片写成“按假设检查容量”，不写成已核验现场布局。

## 结果流程图

流程图放在报告最前面，紧随标题和测算日期，先于预算结论及正文；第三章不重复放图。以相对图片链接嵌入SVG/PNG，提供原图链接与可编辑图源。布局见[理论图示例](../assets/theory-flow.example.svg)：顶部需求/假设，中间显存、Prefill、Decode三分支，汇聚约束比较/布局选择，底部工作卡+备用卡=预算候选。不画实测基线或综合核算分支。

白底、浅蓝圆角节点、灰箭头；未知/限制浅黄，结果浅绿。关键公式和必要数字来自同次结果，假设及近似状态就近标注。实际图不得沿用示例参数和结论。对外只用物理卡、Prefill/Decode和推理实例。大图不靠缩小字塞入全部细节，提供单独查看链接。

校验数据对应、单位、舍入、箭头依赖、工作/备用、图片和本地链接、SVG语法；使用可用工具检查图像裁切、重叠和字体。无法视觉验证时注明，语法解析不等于视觉验收。不为了画图重新做模型下载。

## 多布局报告扩展

用户未锁定布局时，第三章在目标对照之后增加“候选布局比较”：先列各方案Prefill/Decode物理卡、推理实例及备用，再用不超过三列的表展示各方案预算指标、状态和未采用原因，详细代入集中在主要候选及导致小布局失败的约束。不要为每个布局复制整章。

展示同一敏感性场景下的比较，条件候选和预算候选分组，不用未知值当零。不只给最低卡数；说明为什么采用它或选更有余量的方案，以及哪些前提未验证。单布局未改算时不得补写虚假的多布局结论。

图将显存、Prefill、Decode分支汇入“逐候选重算与约束比较”，再分出不满足原因、条件候选、预算候选，最终给采用方案的工作/备用总卡。物理卡、阶段、推理实例与连续公式的表达规则不变。

## 可独立交付与阅读顺序

- 第一章先列客户需求，再列本轮建模方案及工程假设。平均长度、并发和时延目标等业务输入与参考卡数、推理实例、简化调度、效率及开销分开，不能让读者把建模假设误认为现场配置。
- 第三章首次出现关键数值时交代来源和上一层关系。每卡权重须能追溯分组总量、分片与复制；缓存须能追溯每请求逻辑量、附加系数、实例分配和卡内复制。只给最终数值表不够。用合并公式说明，张量逐项清单留附录；仍保持中文变量公式、数字和结果在同一连续等式，不主动拆段。
- 开头集中列结论边界，各计算段只保留该项特有条件，避免反复重复整套“不保证/未验证”声明。目标对照明确区分简化调度平均TTFT与最繁忙实例步长近似TPOT，不能显示成同等级的平均值测量。
- 统一中文、英文和数字间适当空格，运算符两侧留空格，单位一致；模型ID、摘要、代码、URL和原始证据不为排版改写。
- 多布局功能存在不代表本轮已多布局计算。报告列明实际评估范围；仅编辑文档时不补写新布局结论，更小布局需独立运行适配器及比较工具。
- 结论的验证计划按优先级说明“核验什么→需要保留什么材料”。通常先确认目标精度/缓存的支持与输出质量，再核验权重分片和运行资源，最后做同需求口径的时延与吞吐验证。具体内容按模型实际机制调整。

交付文件夹须包含正文、附录、图片及正文/附录引用的必要本地依据。把固定来源的必要快照、修订和摘要归入本地sources，不链接用户机器上的其他outputs、Skill目录或绝对路径。保留官方URL用于追溯，外部链接不替代必要说明。不得默认复制无关测试数据、完整权重或凭据。

提供ZIP及清单，核验交付链接不能越出包根、必要文件存在、来源摘要一致、解压到其他目录后图片及本地依据仍可打开。来源原文内的延伸链接可注明未一并打包。若提供复算，算法/辅助脚本随包保存，明确环境；不要让复算暗中依赖另一份Skill或网络下载。仅生成文档和归档不应重新下载模型资料。
