# D06 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。答案重点是区分训练时的信息限制、生成时的选择策略和自回归循环。

1. Wout 的形状是 **[d,V]**。hWout 得到长度为 V 的向量，其中第 j 个数是词表中第 j 个 Token 的 Logit；再经 Softmax 才得到概率。
2. 若“喝”的表示能读取右侧目标“咖啡”，模型训练时就能偷看答案，但实际生成时目标尚不存在。因果遮罩在 Attention 的 Softmax 前屏蔽未来位置，使“喝”只能读取自己及左侧 Token。
3. 温度公式使用 z/T。T=0.5 时，调整后的 Logit 为 **(4,2,0)**，原来的差距被放大，因此 Softmax 后第一名占据更大概率。
4. top-k=2 保留第 1、2 个位置。top-p=0.8 时，前两个累计概率是 0.75，尚未达到 0.8；加入第三个后为 0.90，因此保留第 1、2、3 个位置。两者之后都需要对保留概率重新归一化。
5. 采样仍按模型概率抽取，高概率 Token 更容易出现，并非所有 Token 等概率。贪心通常对相同输入重复选择同一最高概率 Token；采样可能产生不同结果。
6. 第一轮把“我喜欢喝”送入模型，读取最后位置的 Logit 和概率，选择“咖啡”并追加；第二轮以“我喜欢喝咖啡”为当前序列再次前向计算，选择“。”并追加。之后继续判断是否满足停止条件。
7. 这些参数只改变如何调整、过滤或选择模型已经给出的概率，没有通过损失和反向传播修改权重。因此它们不是训练，也不能创造模型尚未学到的事实，只能改变现有候选的选择倾向。
8. 两者都遵守因果上下文限制。训练时可以在因果遮罩下并行计算序列多个位置的预测与损失，并反向更新参数；生成时通常一次追加一个 Token，使用固定参数反复前向计算，不做梯度更新。

第 1、2 题不清楚时，回看正文第 1、2 节；第 3～5 题不清楚时，回看第 3、4 节；第 6～8 题不清楚时，回看第 5～7 节。
