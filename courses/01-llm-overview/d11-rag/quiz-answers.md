# D11 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。答案重点是把检索、上下文组装、生成与引用连接起来，并沿证据流定位错误。

1. 检索结果仍是材料，可能包含多个版本或分散信息。生成模型负责依据真正进入上下文的证据筛选、归纳并表达最终答案。
2. Retrieve 是检索并重排相关文本；Augment 是把选中的资料连同规则和问题组装进本次上下文；Generate 是模型依据上下文生成答案。资料在 Augment 阶段进入本次上下文。
3. 引用标记只指向资料，不证明资料支持句中全部结论。“户口簿”无法从 S1 得出，因此属于无依据补充。
4. S1 未进入候选属于检索或召回失败，应检查切分、索引和检索表示；S1 已在候选却未进入上下文，属于重排、过滤或长度截断问题。
5. 应优先检查生成指令、上下文噪声、引用对应和模型能力。正确证据已经进入实际上下文，问题不再是“没找到材料”，而是模型没有忠实使用它。
6. 外部资料可能过期、越权或包含恶意诱导。提前过滤可以避免敏感或错误版本已经暴露给模型，也防止把资料正文误当作高优先级指令。
7. 两段现成文字直接放入上下文；大量且常更新的制度使用 RAG；稳定输出风格先用提示词验证，仍需长期稳定时再考虑微调；真正提交申请必须使用受程序校验的工具调用。

第 1、2 题不清楚时回看第 1、2 节；第 3 题回看第 3 节；第 4～6 题回看第 4 节；第 7 题回看第 5 节。
