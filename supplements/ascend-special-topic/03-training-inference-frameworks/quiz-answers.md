# 模块 03 自测题参考答案

1. PyTorch 提供模型、张量、自动微分和优化器等框架抽象；TorchNPU 把 PyTorch 后端接到昇腾并提供 NPU 适配能力；CANN 提供图、算子、运行时、通信和设备执行基础。
2. MindSpeed 运行在基础框架和昇腾软件栈之上。框架、TorchNPU、CANN、驱动、算子包或模型支持不兼容时，训练加速套件也无法建立可靠执行路径。
3. 图模式的收益依赖形成足够大的稳定计算图。动态形状、图断裂、回退或输入变化造成的重编译可能使编译成本超过执行收益；应分析图捕获与编译数据，再调整或选择适用范围。
4. 生产服务还要验证并发调度、KV Cache 容量、TTFT/TPOT、吞吐、流式返回、错误输入、超时、限流、故障恢复和长时间稳定性，并确认输出质量没有下降。
5. 既有 TensorFlow 资产要重点评估受支持版本、迁移成本、算子和长期维护；新项目可以从当前生态、模型支持、团队经验、训练规模、推理引擎与维护周期重新选择，不必继承旧版本约束。
6. 一条合理链路是：数据与 Qwen 模型 → PyTorch + TorchNPU → MindSpeed SFT → CANN/NPU → 新检查点；推理阶段从新检查点开始，可直接进入 vLLM-Ascend，也可由 MindIE Motor 接入 vLLM-Ascend，再经 CANN/NPU 对外提供在线 API。参数更新结束、固定权重被加载处是训推分界。
