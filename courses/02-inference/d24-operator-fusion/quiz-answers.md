# D24 自测题参考答案

1. A 把中间张量 Z 写入显存，B 随后又从显存读取 Z；若 Z 只供 B 使用，这次往返可能被片上暂存替代。
2. Kernel 启动、Kernel 之间的同步以及 CPU 或运行时提交工作等固定成本。
3. 每个线程占用资源更多会降低同时驻留的线程块数量，使 GPU 难以维持足够并行工作。
4. 后端难以复用固定的计算图、内存规划和专用 Kernel，可能需要重新选择或编译执行方案。
5. 总体影响通常有限，因为优化的是总耗时中的很小部分；应先依据热点占比判断。
6. 融合主要改变算子组织和中间数据移动；量化主要改变数值表示、存储字节数和可能使用的计算路径。
