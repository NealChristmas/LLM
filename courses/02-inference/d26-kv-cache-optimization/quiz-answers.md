# D26 自测题参考答案

1. MQA/GQA 减少 KV 头数；KV 量化减少每元素字节数；滑动窗口减少保留和访问的历史 Token 数。
2. 它改变缓存的物理分块和逻辑映射，减少预留与碎片；K/V 的内容和每个 Token 应保存的数据可以保持不变。
3. 分析每 Token KV 大小、活动 Token 总量、KV 数据类型、模型 KV 头结构、长度策略和缓存分配浪费。
4. 主体约减半；还需验证后端支持、实际速度、长上下文和目标任务质量。
5. KV 头共享属于注意力层参数结构，通常需要模型训练或受支持的转换与质量验证。
6. 任务需要引用窗口之外的早期信息，或模型本身不支持相应注意力语义时。
