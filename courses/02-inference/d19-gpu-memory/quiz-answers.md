# D19 自测题参考答案

1. 同一数据从较近的片上存储被复用，可以减少较慢的显存读取次数，使计算单元少等待。
2. 前者是容量问题：数据能否放下；后者是性能问题：计算、带宽、并行规模和调度能否高效配合。
3. 它用较大的主机内存扩展可用容量，但压力转移到 CPU 与 GPU 之间的互连带宽和传输延迟。
4. 权重通常在模型加载后长期固定；KV Cache 属于请求状态，会随活动请求数量和序列长度增长，并在请求结束后释放。
5. 缓存会频繁替换数据，之后再次使用时需要从更远存储重新读取，复用收益下降。
6. 占用率只反映容量使用，不能说明显存带宽、计算单元、CPU 提交或跨设备传输是否成为瓶颈。
