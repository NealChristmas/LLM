# 模块 05 自测题参考答案

1. 工厂质检更强调产线节拍、断网运行、相机适配和漏检/误检；医疗影像更强调敏感数据、院内系统集成、可追溯和医生复核。相同模型受到不同数据位置、风险和流程约束，部署与验收自然不同。
2. 包括低时延要求、网络不稳定、原始数据量过大、数据不能外传、现场必须自治、中心带宽成本高，以及只需上传事件而非原始流等。
3. 上线还要验证知识正确性、引用、权限、隐私、提示注入、工具调用副作用、峰值并发、故障恢复、限流降级、人工接管和审计。压测快只覆盖性能的一部分。
4. 可复用的是业务问题、部署层级、组件关系和指标类型；准确率、吞吐、时延、效率提升及成本等数值必须在自己的数据、模型、硬件和测试口径下复测。
5. 摄像头或边缘模块就地识别并保留短期缓存，将告警和抽样图像上传区域中心，中心负责复核、模型管理和跨点位分析。断网时边缘继续按最近已验证模型运行并缓存事件，恢复后补传；无法判断的样本进入人工巡检队列。
6. 缺少具体医疗任务与失败代价、数据来源和隐私边界、模型与质量基线、并发和时延负载、为何选择对应产品形态、完整软件版本组合、与医院系统的接口、人工责任，以及性能、质量、安全、可靠性、成本和回退标准。
