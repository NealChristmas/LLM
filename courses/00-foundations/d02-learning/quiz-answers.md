# D02 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。重点是能解释原因，不要求背诵术语定义。

1. **都是 2**：½×(8−10)²=2，½×(12−10)²=2。平方损失不保留偏差方向；需要看预测与目标的大小关系，或误差 ŷ−y 的符号。
2. **2.8**：3−0.1×2=2.8。正梯度表示当前位置稍微增大参数会让损失上升，所以梯度下降往减小方向移动。
3. **w₂ 先影响预测，预测再影响损失**。预测对 w₂ 的变化率是 x₂=2；损失对预测的变化率是 ŷ−y=−1。连乘得到 −2，不能直接把误差 −1 当作每个参数的梯度。
4. 漏掉了**优化器更新参数**。反向传播算出梯度，之后才按学习率和更新规则修改参数；仅计算梯度不会改变权重。
5. **步长太大，跨过了低损失区域**。梯度描述当前位置的局部变化率，而不是任意距离的保证。同样的旧参数与梯度，学习率 0.1 时预测为 9.6、损失为 0.08；学习率 1 时预测为 15、损失为 12.5。
6. **不一定**。更新依据是批内平均损失的梯度；样本之间的调整方向可能冲突，所以整体改善不保证每条都改善。
7. **不能**。输入背景改变，本来就可能改变同一组权重算出的结果。普通推理没有“计算训练损失→反向传播→优化器更新权重”的训练循环。

若第 2、3、5 题不清楚，回看正文第 2～4 节，抓住“局部变化率”和“步长”的区别；若第 4、7 题混淆，回看第 5 节的训练循环。
