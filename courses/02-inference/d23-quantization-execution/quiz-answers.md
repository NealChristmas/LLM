# D23 自测题参考答案

1. Kernel 通常会按分组和尺度反量化，或者进入硬件支持的低精度混合计算路径，再与激活完成矩阵运算。
2. 速度还取决于是否有高效的 4 位 Kernel、反量化开销、算子是否受带宽限制以及硬件支持。
3. 尺度必须覆盖极端值，格子间距因此变大，普通小值更容易被映射到相同编号，近似误差增加。
4. 训练数据用于学习参数；量化校准数据用于观察部署时激活或权重范围，确定缩放和截断策略，不更新模型能力。
5. 权重量化只缩小权重，KV Cache 仍随活动请求和序列长度增长，可能继续耗尽剩余显存。
6. 固定模型版本、请求集、输入输出长度、硬件、引擎和并发，分别比较峰值显存、质量、TTFT、TPOT 与吞吐。
