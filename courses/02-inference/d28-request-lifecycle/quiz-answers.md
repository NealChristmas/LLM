# D28 自测题参考答案

1. 校验 Prompt 和生成上限、采样参数、模型或适配器选择及请求标识，并确认是否符合服务边界；随后等待调度资源。
2. 长请求会阻塞后续短请求，GPU 批次空位也难及时利用；迭代级调度可以在请求之间共享每轮资源。
3. 调度器产生本轮 Token 计划；执行器产生模型 Logit；采样器根据 Logit 和采样参数选择新 Token。
4. 请求还要继续 Decode，后续每个 Token 都需读取历史 K/V，因此缓存仍是活动状态。
5. 二者都使请求停止后续调度并释放资源；EOS 由模型输出触发，取消由客户端或上层控制信号触发。
6. 输入非法应在入口确定性拒绝；KV 分配失败是动态容量问题，可能通过排队、抢占或限流处理。
