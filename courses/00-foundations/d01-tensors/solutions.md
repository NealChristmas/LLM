# D01 提示与参考答案

先完成[练习](exercises.md)。每题先给提示，再给过程；核对后保留初答，另写修正理由。无需与这里措辞完全一致。

## E1

提示：分别数“有几个轴”和“每个轴长度是多少”；语义来自数据约定。

答案：[4, 3]，2 个轴，12 个元素；第 0 轴为样本，第 1 轴为特征。增加两个样本后是 [6, 3]。另一张同形状的表可能代表四个时间点、三个传感器，不能仅从 shape 推断含义。

常见误解：把 [4, 3] 称为“4 维张量”；把 shape 相同视为样本语义相同。

## E2

提示：逐元素乘法取相同位置；矩阵乘法取左行与右列。

```text
A * C = [[2, 4],
         [0, 15]]

A @ C = [[4, 13],
         [6, 15]]
```

第一行第二列：2×4 + 1×5 = 13。左上角：2×1 + 1×2 = 4。两种结果都是 [2, 2]，shape 检查无法替代数值与运算语义检查。

常见误解：两种乘法都有乘号，所以可互换；相同 shape 表示算法正确。

## E3

提示 1：X 是 [2, 3]，实际 W 需要 [3, 2]。

提示 2：每个输出对应的一组权重应成为一列；转置把原来的行变为列。

```text
W = [[ 1, 2],
     [ 0, 1],
     [-1, 0]]

XW = [[-2,  4],
      [-2, 13]]
```

第一条样本的第一个输出是 1×1 + 2×0 + 3×(-1) = -2，第二个输出是 1×2 + 2×1 + 3×0 = 4。第二条样本同理得到 [-2, 13]。结果 shape 为 [2, 2]，分别代表两条样本和两个输出。

直接 X @ W_stored 的内维度是 3 和 2，不相等。应将 W_stored 转置，而不是任意改变元素排列。比如仅顺序重排为 [[1,0],[-1,2],[1,0]] 虽可相乘，却更换了每个输出使用的特征权重，计算含义已改变。

常见误解：把所有形状问题都用 reshape 消除；修复了报错，却未保留模型语义。

## E4

提示：输出数 O 决定 W 的列数和偏置长度，B 只表示同时输入多少样本。

| B | X | W | b | Y |
| --- | --- | --- | --- | --- |
| 4 | [4, 2] | [2, 3] | [3] | [4, 3] |
| 7 | [7, 2] | [2, 3] | [3] | [7, 3] |

权重数 2×3 = 6，偏置数 3，参数总数 9。每个输出需要一套权重和一个偏置，这套映射应用到每条样本，不随批次扩充。

注意：这里讨论这一层的参数量，不是在计算完整模型内存；运行时还需要输入、中间结果等。

## E5

提示：只有 w₁ 变化，输出变化量就是 x₁ × (4−2)。

原结果 [9, 19, 29]，改后 [11, 25, 39]，变化量 [2, 6, 10]。三条样本的 x₁ 分别为 1、3、5，因此变化不相同。

本课计算固定且没有自动参数更新，重复执行仍使用同样的输入和权重，不会自行改善。人工指定 w₁ = 4 也没有证明模型变好，因为尚未定义目标答案和误差标准。

地图上补的是 P1“输入经过参数得到输出”。训练还要定义目标与损失，并根据梯度等规则更新参数（P2/P3）；处理真实文本还要有编码、语言模型结构和生成流程（P4）。P1 的计算既可出现在训练的前向阶段，也可用于已有模型的推理。

## 热身与闭卷回顾核对

把文档加入当前上下文通常是改变本次输入，而不是更新模型权重。前向计算在训练和推理中都会发生。权重是处理输入的模型参数，样本属于输入；输出变了可能来自输入或参数变化，不能单凭结果变化判断发生了训练。

进入 D02 前，至少能够独立解释形状匹配、手算一个矩阵乘法元素、区分输入与参数、解释改参影响。尚有困难时，把矩阵运算还原成每条样本的加权求和，重新做对应题即可。
