# D18 自测题参考答案

1. 算子描述“要算什么”，包括输入、输出和数学规则；Kernel 描述“在目标 GPU 上具体怎样算”，包括分块、线程和数据访问；GPU 是真正执行 Kernel 的物理硬件。
2. 每个输出区域都读取 X 的相应行和 W 的相应列，但不需要等待其他输出区域的最终结果，因此可以独立分配给不同线程组并行计算。
3. 不同输入形状、数据类型和 GPU 硬件适合不同的分块、线程数量与数据访问方式；算子语义相同，最高效的具体实现可能不同。
4. 后一个 Kernel 需要前一个 Kernel 的输出；在输出尚未产生时启动后一个 Kernel，没有完整输入可用。
5. Prefill 一次处理许多 Token，计算规模较大；Decode 每步只增加少量 Token，并反复读取不断增长的 KV Cache，因此并行规模和数据访问比例不同。
6. 不一定。如果瓶颈是显存读写而不是计算能力，增加计算单元仍要等待数据，收益会很小。
