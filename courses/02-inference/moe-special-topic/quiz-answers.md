# MoE 推理专题自测题参考答案

1. 因为模型根据当前 Token 的隐藏向量选择部分专家参数参与计算，而不是让每个输入使用全部专家参数。
2. 专家总参数量为 8×5B=40B；单 Token 激活的专家参数量为 2×5B=10B。这里还没有计入 Attention、路由器等共享参数。
3. 未被当前 Token 激活的专家并未删除，其他 Token 仍可能使用它们，因此部署仍要保存全部 100B 权重；20B 主要描述当前激活路径的参数规模。
4. 路由器读取的是包含上下文的当前层隐藏向量，不是孤立的 Token ID；上下文不同会产生不同隐藏向量和专家分数。
5. 权重存储按总参数量估算：47B×2字节=94GB。13B 激活参数主要影响单 Token 计算路径，不能替代总权重规模。
6. 专家通常替换 FFN，而 KV Cache 保存 Attention 的 K、V；其大小主要取决于层数、KV 头、头维度、Token 数和缓存精度。
7. 可能慢在路由与 Token 重排、专家批次太小、专家负载不均，以及专家分布在多卡时的 All-to-All 通信。
8. 密集模型通常让每个 Token 使用大部分主要参数，MoE 只激活部分专家。公平比较还要同时看激活参数、质量、精度、硬件互联、负载和通信成本。
