# D09 自测参考答案

先完成[正文末尾的自测](README.md)，再核对。答案重点是区分模型参数与当前上下文，并根据影响范围选择方案。

1. 新要求作为本次输入 Token 参与 Attention 和下一 Token 概率计算，所以会影响当前回答；没有计算训练损失、反向传播和参数更新，因此请求结束后权重没有永久变化。
2. 示例：“根据下方报告，找出导致本季度成本上升的三个主要原因；每个原因用一句话说明并引用原文数据，不推测报告未提供的原因。报告：……”其中分别给出了分析任务、报告材料、三点及引用格式和不补充未知信息的边界。
3. 属于少样本提示下的上下文学习（Few-shot In-context Learning）。模型依据当前输入中的示例生成结果，没有因此执行梯度下降或更新参数。
4. 本次上下文必须包含能确定该格式的信息，例如此前的用户要求和助手回答，或者由应用生成的准确摘要。如果相关历史没有传入，模型无法仅凭“刚才”恢复内容。
5. 它位于待处理文档中，作用是被总结而不是改变任务，所以应被视为材料。分隔和标注只能帮助模型区分角色，不能改变生成具有概率性这一事实，因此不能提供绝对安全保证；完整防护要到后续 RAG 和工具调用部分再展开。
6. 应用可能拒绝请求、截断较早历史、压缩历史或文档，或者减少输出预算，具体取决于实现。扩大窗口只能提高可容纳的 Token 数；无关内容仍可能干扰，模型也未必可靠使用长文本中的每个位置。
7. 错误。制度只是当前上下文中的临时信息，模型可以在本次回答中使用；没有训练过程就不会把它永久写入参数，后续请求还需要再次提供。
8. 改变一次回答格式用提示词；长期稳定分类行为考虑微调；查询每日变化的制度使用 RAG 检索最新资料并加入上下文；真正执行退款必须使用受权限和参数校验控制的工具调用。

第 1～3 题不清楚时，回看正文第 1～3 节；第 4、5 题不清楚时，回看第 4 节；第 6、7 题不清楚时，回看第 5、6 节；第 8 题不清楚时，回看第 7 节。
