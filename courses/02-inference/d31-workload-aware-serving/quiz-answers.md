# D31 自测题参考答案

1. 应用名称不能给出输入输出长度、到达率、并发和共享前缀，这些才直接决定 Prefill、Decode、缓存与排队。
2. 一组可能长度均匀，另一组长短极端混合；即使平均相同，批次不均、缓存峰值和尾部阻塞会不同。
3. 离线吞吐可能提高；交互请求可能因等待成批和长轮次而增加 TTFT 或输出抖动。
4. 多步骤请求常重复系统提示、工具说明和部分历史，复用这些前缀可减少重复 Prefill。
5. 总流量很小、不同类型并不互相干扰，或拆池后每个实例都无法形成有效批次时。
6. 输出越长，请求占用 Decode 轮次和 KV Cache 越久；相同并发数可能对应完全不同的持续资源压力。
