# D01 独立练习

历史实操练习：当前不要求完成，请使用[正文末尾的快速自测题](README.md)，答案见 [quiz-answers.md](quiz-answers.md)。

总计 50 分钟。E1～E4 先手算和解释，E5 再运行实验。可查必要 API；无需编写通用算法或背语法。作答写在 [D01 学习记录](../../../notes/d01.md)，保留第一次判断和之后的修正。

## E1：形状不是只有一串数字（5 分钟，G1）

有四个样本，每个样本包含三个数值特征，按“一行一个样本”排列。

1. 写出 shape、轴数、元素数，并说明各轴含义。
2. 增加两个样本，形状如何变化？
3. 另一张数据表的 shape 也是 [4, 3]，能否直接断定第一个轴仍是样本？解释理由。

提交：三个回答。完成标准：区分形状和语义。

## E2：相同形状，不同计算（10 分钟，G2）

```text
A = [[2, 1],       C = [[1, 4],
     [0, 3]]            [2, 5]]
```

计算 A * C 与 A @ C，写出完整矩阵，至少展示后者第一行第二列的计算过程。若只比较输出 shape，能否发现把两种运算写反的错误？

提交：两个矩阵、一步手算和一句判断。完成标准：说清对应位置相乘与行列加权求和的区别。

## E3：修复轴含义，不仅是让代码运行（10 分钟，G2）

```text
X = [[1, 2, 3],       W_stored = [[1, 0, -1],
     [4, 5, 6]]                   [2, 1,  0]]
```

X 每行是一条样本，包含三个特征。W_stored 每行是一个输出所需的三个权重，共有两个输出。本题不加偏置。

1. 为什么直接 X @ W_stored 不成立？
2. 应怎样排列权重才能保持原有特征对应关系？写出实际参与乘法的矩阵。
3. 计算修复后的结果及 shape。
4. 如果另一种重排也能让形状相乘，是否就一定正确？

提交：原因、权重矩阵、结果、语义解释。完成标准：两个输出各自保留原来的一整组权重。

## E4：批次改变，模型需要改变吗（10 分钟，G3）

先读[多输出与偏置补充](shape-extension.md)，再独立作答。

某模型每条输入有 2 个特征，产生 3 个输出，采用 Y = XW + b，每个输出有一个偏置，所有样本共享模型参数。

1. B = 4 时，X、W、b、Y 的形状分别是什么？
2. B = 7 时，哪些形状改变？
3. 参数总数是多少？偏置为什么不是每条样本单独一份？

提交：两组形状与解释。完成标准：不把样本数计入模型参数数目。

## E5：用实验验证因果判断（15 分钟，G4）

使用[配套实验 B](practice.md)的 X、W 和 b。先不运行，预测把 w₁ 从 2 改为 4 后：

1. 每个样本的输出及相对于原结果的变化量。
2. 为什么变化量不都相同？
3. 运行 `experiments.py b --first-weight 4` 核对；若不同，写出错误原因。
4. 不改变输入和参数，只把前向运行一千遍，会让本课模型自动学得更好吗？为什么？
5. 在整体地图上说明：本实验补全了什么？距离训练还缺什么？距离处理真实文本还缺什么？

提交：运行前预测、运行结果、解释和地图定位。完成标准：分清输入变化、人工改参、前向计算与训练。

完成后再看[提示与参考答案](solutions.md)。能修正自己的推理错误，比第一遍全部答对更有价值。
